# IMENA Brand

Website for **IMENA Brand** (`@imena_luxe_prints`) — Rwanda pride jerseys and custom luxe prints.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Order flow

Product and contact buttons open WhatsApp to **+250 780 814 163** with a pre-filled order message.
